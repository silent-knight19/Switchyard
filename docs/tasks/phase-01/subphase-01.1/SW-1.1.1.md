## Goal

- An accessible Switchyard Git repository/worktree. Inspect its state first; if none exists, stop and report that prerequisite rather than inventing an unrelated repository.

## In scope
- Root `package.json`: private workspace root, `packageManager` pinned to an exact pnpm version, stable metadata and minimal package-manager checks as appropriate.
- Root pnpm workspace definition (`pnpm-workspace.yaml`) matching specified future app/package layout. Directories may be listed before app content exists.
- Node version pin using one documented consistent mechanism (`.node-version`, `.nvmrc`, or `.tool-versions`), with exact LTS patch number verified against official Node release information during implementation.
- `pnpm-lock.yaml` generated by the chosen pinned pnpm version and committed for future `--frozen-lockfile` installs.
- Root `.npmrc` or equivalent settings only when required for reproducible install behavior.
- Concise toolchain section in root README or a small `docs/DEVELOPMENT.md`, if repository conventions exist.
- `.gitignore` only where needed to exclude `node_modules`, local secrets, build artifacts and temporary files; never ignore the lockfile.
